# OpenAPI
Project Overview

This project uses the Open Meteo API to provide full functionality to the web applicatiob. To run the app on your local machine, please follow the steps below:

1. Clone the Repository
Ensure you are logged into GitHub. Click the "Code" button on this repository to copy the repository link. You cab choose to use either SSH or HTTPS.

2. Open Your IDE

Launch your preferred integrated Development Environment (IDE) and open the terminal. 


3. Clone the Repository
Run the following command in the terminal, replacing [insert repo url] with the copied repository link:

git clone [insert repo url]


4. Navigate to the Project Folder

Make sure you are in the correct directory on your local machine where the repository has been cloned.

5. Run the Project
